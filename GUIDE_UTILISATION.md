# 📖 Guide d'Utilisation - Kayniou Liggey

## Bienvenue sur Kayniou Liggey ! 🎉

Kayniou Liggey est votre plateforme de confiance pour trouver et engager des travailleurs qualifiés au Sénégal.

---

## 🚀 Démarrage Rapide

### Pour les CLIENTS

#### 1. **Inscription** (2 minutes)
1. Téléchargez l'app depuis Play Store/App Store
2. Appuyez sur "S'inscrire"
3. Choisissez "CLIENT"
4. Renseignez :
   - Nom complet
   - Numéro de téléphone
   - Localisation
   - Mot de passe sécurisé
5. Validez !

#### 2. **Créer votre première demande**
1. Sur l'écran d'accueil, appuyez sur **"+"**
2. Sélectionnez la catégorie de service :
   - 🔧 Plomberie
   - ⚡ Électricité
   - 🪵 Menuiserie
   - 🧱 Maçonnerie
   - 🎨 Peinture
   - 🌿 Jardinage
   - 🧹 Nettoyage
   - 🚗 Mécanique
   - Et 5 autres...

3. **Décrivez votre besoin** :
   - Soyez précis et détaillé
   - Mentionnez l'urgence si nécessaire
   - Ajoutez 2-5 photos de qualité

4. **Choisissez votre mode** :
   - 📢 **Enchères publiques** : Tous les workers voient (meilleurs prix)
   - 🔒 **Enchères privées** : Invitez 1-10 workers spécifiques
   - ⚡ **Embauche directe** : Engagez un worker immédiatement

5. Validez et attendez les devis !

#### 3. **Recevoir et comparer les devis**
- Vous recevez des notifications en temps réel
- Consultez chaque devis détaillé
- Vérifiez les profils des workers :
  - ⭐ Note et avis
  - ✅ Missions terminées
  - 📍 Distance
  - 💰 Tarifs

#### 4. **Choisir le bon worker**

**Critères recommandés** :
- Note minimum : 4/5 ⭐
- Au moins 5 missions terminées
- Avis positifs récents
- Prix raisonnable (pas le moins cher = meilleure qualité)

**Avant d'accepter** :
- Posez des questions via le chat intégré
- Demandez des photos de travaux similaires
- Clarifiez les détails (matériel inclus ? délais ?)

#### 5. **Pendant le chantier**
- Communiquez via le chat en temps réel
- Suivez l'avancement
- Signalez tout problème immédiatement
- Prenez des photos avant/après

#### 6. **Finalisation et évaluation**
- Vérifiez que le travail est conforme
- Effectuez le paiement (direct avec le worker)
- **ÉVALUEZ LE WORKER** :
  - Note globale (1-5 étoiles)
  - Notes détaillées : qualité, ponctualité, communication, professionnalisme
  - Commentaire (minimum 10 caractères)
  - Recommanderiez-vous ? Oui/Non

---

### Pour les WORKERS

#### 1. **Inscription professionnelle**
1. Téléchargez l'app
2. Choisissez "S'inscrire" puis "WORKER"
3. Renseignez :
   - Nom complet
   - Téléphone
   - Localisation
   - Mot de passe

4. **Complétez votre profil** :
   - Sélectionnez vos compétences (jusqu'à 5 catégories)
   - Années d'expérience
   - Description détaillée de vos services
   - **Photos de vos travaux** (minimum 3, qualité professionnelle)
   - Tarifs horaires ou forfaitaires
   - Disponibilités

#### 2. **Trouver des missions**

**3 façons** :
1. **Parcourir les demandes** :
   - Consultez toutes les demandes publiques
   - Filtrez par catégorie et proximité

2. **Recevoir des invitations** :
   - Les clients peuvent vous inviter directement
   - Notifications en temps réel

3. **Embauches directes** :
   - Les clients fidèles vous engagent sans enchères

#### 3. **Soumettre un devis professionnel**

**Contenu d'un bon devis** :
- **Prix détaillé** :
  - Main d'œuvre
  - Matériaux (inclus ou à la charge du client)
  - Transport si applicable
  - TOTAL TTC

- **Délais** :
  - Date de début proposée
  - Durée estimée
  - Date de fin prévisionnelle

- **Description** :
  - Étapes du travail
  - Matériaux utilisés
  - Garanties offertes

- **Conditions** :
  - Acompte éventuel
  - Modalités de paiement
  - Conditions d'annulation

💡 **Conseil** : Les devis détaillés et clairs ont 3x plus de chances d'être acceptés !

#### 4. **Si votre devis est accepté**
- Vous recevez une notification
- Le chantier est créé automatiquement
- Contactez le client pour :
  - Confirmer le rendez-vous
  - Préciser les derniers détails
  - Partager votre localisation si nécessaire

#### 5. **Réalisation du chantier**
- Respectez l'horaire convenu
- Communiquez en cas de retard ou imprévu
- Prenez des photos avant/pendant/après
- Partagez l'avancement via le chat
- Maintenez la zone de travail propre

#### 6. **Fin de mission**
- Faites valider le travail par le client
- Recevez votre paiement
- **ÉVALUEZ LE CLIENT** :
  - Ponctualité
  - Communication
  - Respect des conditions
  - Recommanderiez-vous ?

**Pour les clients** :
1. Appuyez sur **"Recherche IA"** (icône ✨)
2. Décrivez votre problème en langage naturel :
   - ✅ Bon : "J'ai une fuite d'eau urgente sous mon évier de cuisine"

## 🛡️ Sécurité et Confiance

### Règles de Sécurité

✅ **À FAIRE** :
- Vérifiez toujours les avis avant d'engager
- Utilisez le chat intégré (traçable)
- Prenez des photos avant/après travaux
- Demandez une visite gratuite si gros travaux
- Payez uniquement après validation
- Signalez les comportements suspects

❌ **À NE PAS FAIRE** :
- Payer l'intégralité à l'avance
- Partager des informations bancaires par chat
- Engager sans vérifier le profil
- Accepter un prix trop bas (suspect)
- Ignorer les signaux d'alerte

### Signalement et Blocage

**Vous pouvez signaler** :
- Comportement inapproprié
- Fraude ou arnaque
- Non-respect des engagements
- Harcèlement
- Qualité inacceptable

**Processus** :
1. Allez sur le profil de l'utilisateur
2. Menu (3 points) > "Signaler"
3. Choisissez la raison
4. Décrivez la situation
5. Ajoutez des preuves (captures d'écran, photos)

Notre équipe examine tous les signalements sous 48h.
