## 1. Présentation de l'application

**Kayniou Liggey** (qui signifie "Chercher du travail" en Wolof) est une application mobile de mise en relation entre **clients** qui ont besoin de services et **travailleurs qualifiés** (workers) dans différents corps de métiers.

### Catégories de services disponibles

| Icône | Catégorie | Description |
|-------|-----------|-------------|
| 🔧 | Plomberie | Réparation de fuites, installation sanitaire, débouchage |
| ⚡ | Électricité | Installation électrique, dépannage, mise aux normes |
| 🪚 | Menuiserie | Fabrication de meubles, réparation de portes/fenêtres |
| 🧱 | Maçonnerie | Construction, rénovation, travaux de gros œuvre |
| 🎨 | Peinture | Peinture intérieure/extérieure, décoration |
| 🔲 | Carrelage | Pose de carrelage, faïence, mosaïque |
| 🌱 | Jardinage | Entretien de jardin, aménagement paysager |
| 🧹 | Nettoyage | Nettoyage professionnel, entretien de locaux |
| 📦 | Déménagement | Transport de meubles, déménagement complet |
| 🔨 | Réparation | Réparation générale, bricolage |
| 🔧 | Installation | Installation d'équipements, montage |
| ❄️ | Climatisation | Installation et réparation de climatiseurs |
| 🔩 | Mécanique | Réparation automobile, mécanique générale |

## 2. Installation et premier lancement

### Prérequis
- Téléphone Android (version 6.0 ou supérieur)
- Connexion Internet (Wi-Fi ou données mobiles)
- GPS activé (pour la géolocalisation)

### Installation
1. Téléchargez le fichier APK de Kayniou Liggey
2. Ouvrez le fichier APK sur votre téléphone
3. Si demandé, autorisez l'installation depuis des sources inconnues
4. L'application s'installe automatiquement

### Premier lancement
Au premier lancement, l'application affiche la **page d'accueil** avec :
- Une présentation de l'application
- Le bouton **"Commencer maintenant"** pour s'inscrire
- Le bouton **"Connexion"** pour les utilisateurs existants
- La section **"Comment ça marche"** en 3 étapes
- Les **catégories populaires** de services
- Les **offres d'abonnement** pour les professionnels (Basique et Premium)

## 3. Inscription et connexion

### 3.1 Créer un compte

1. Depuis la page d'accueil, appuyez sur **"Commencer maintenant"**
2. Remplissez le formulaire d'inscription :
   - **Nom complet** : Votre prénom et nom (minimum 3 caractères)
   - **Email** : Votre adresse email valide
   - **Numéro de téléphone** : Sélectionnez votre pays (détecté automatiquement par GPS) puis entrez votre numéro
   - **Mot de passe** : Minimum 6 caractères
   - **Confirmer le mot de passe** : Retapez le même mot de passe
3. Appuyez sur **"Continuer"**

### 3.2 Vérification OTP (code SMS)

Après l'inscription, vous recevez un code de vérification par SMS :
1. Entrez le **code à 5 chiffres** reçu par SMS
2. Appuyez sur **"Vérifier"**
3. Si vous n'avez pas reçu le code, appuyez sur **"Renvoyer le code"** (disponible après 60 secondes)

**Note** : En cas de problème avec la réception du SMS, vous pouvez utiliser le code universel de test : **12345**

### 3.3 Choix du type de profil

Après la vérification, choisissez votre type de profil :

#### Option 1 : Client
- Sélectionnez **"Client"** si vous cherchez des travailleurs pour vos projets
- Vous serez redirigé vers l'accueil client

#### Option 2 : Worker (Travailleur)
- Sélectionnez **"Worker"** si vous proposez vos services
- Vous devrez ensuite :
  1. **Sélectionner vos catégories de métiers** (au moins une)
  2. **Remplir vos informations détaillées** : expérience, description, tarif horaire, etc.

### 3.4 Se connecter (compte existant)

1. Depuis la page d'accueil, appuyez sur **"Connexion"**
2. Entrez votre **numéro de téléphone** et votre **mot de passe**
3. Appuyez sur **"Se connecter"**

## 4. Guide Client

### 4.1 Accueil Client (Carte)

L'écran d'accueil client affiche une **carte interactive** avec :

- **Les travailleurs disponibles** à proximité (affichés comme des marqueurs sur la carte)
- **Un compteur** en bas à gauche indiquant le nombre de travailleurs proches (ex: "5 travailleurs à proximité")
- **Un filtre de catégories** en haut (barre horizontale scrollable) :
  - "Tous" : affiche tous les travailleurs
  - Plomberie, Électricité, Menuiserie, Maçonnerie, Peinture, Jardinage, Nettoyage
- **Boutons d'action** :
  - **Bouton "+" (bleu, en bas à droite)** : Créer une nouvelle demande de service
  - **Bouton "Recherche IA" (orange, à droite)** : Lancer une recherche intelligente par texte libre
  - **Bouton chatbot (orange, en bas à gauche)** : Ouvrir l'assistant chatbot
  - **Bouton recentrer (blanc, à droite)** : Recentrer la carte sur votre position

**Appuyez sur un marqueur** pour voir les détails du travailleur.

### 4.2 Créer une demande de service

Pour créer une demande, appuyez sur le **bouton "+"** depuis l'accueil, puis suivez les 2 étapes :

#### Étape 1 : Informations de base

- **Titre de la demande** : Un titre court et clair (ex: "Réparation de fuite d'eau")
- **Description détaillée** : Expliquez en détail le travail à effectuer
- **Catégories** : Sélectionnez une ou plusieurs catégories de services concernées (obligatoire)
- **Niveau d'urgence** :
  - **Faible** : Pas de pression de temps
  - **Moyenne** : À réaliser dans un délai raisonnable
  - **Urgente** : Intervention rapide nécessaire

Appuyez sur **"Suivant"** pour passer à l'étape 2.

#### Étape 2 : Détails et budget

- **Budget estimé** : Entrez le montant que vous souhaitez payer (en monnaie locale : FCFA, GHS, NGN, etc.)
- **Mode de demande** (3 options) :

  | Mode | Description | Utilisation |
  |------|-------------|-------------|
  | **Direct** | Assignez directement à un travailleur spécifique | Quand vous connaissez déjà le travailleur |
  | **Enchères Publiques** | Tous les workers voient la demande et soumettent des devis. Tous les devis sont visibles. | Pour obtenir le meilleur prix |
  | **Enchère Privée** | Tous les workers voient la demande, mais chaque worker ne voit que son propre devis. Vous seul voyez tous les devis. | Pour une mise en concurrence confidentielle |

- **Durée de l'enchère** (visible en mode Enchères/Privée) :
  - 12 heures
  - 24 heures (1 jour)
  - 48 heures (2 jours) - **par défaut**
  - 72 heures (3 jours)
  - 7 jours

- **Sélection du worker** (en mode Direct uniquement) : Appuyez pour sélectionner un travailleur parmi ceux disponibles dans votre catégorie

- **Localisation** : Détectée automatiquement par GPS. Vous pouvez la modifier ou préciser l'adresse manuellement.

Appuyez sur **"Créer la demande"** pour publier.

**Important** : Une fois la durée de l'enchère écoulée, la demande passe automatiquement au statut **"Expirée"** et les workers ne pourront plus soumettre de devis.

### 4.3 Mes demandes

L'onglet **"Demandes"** dans la barre de navigation affiche toutes vos demandes de service.

Chaque demande affiche :
- Le titre
- La catégorie
- Le statut (badge coloré) :

| Statut | Couleur | Signification |
|--------|---------|---------------|
| En attente | Jaune/Orange | La demande vient d'être créée, en attente de devis |
| Active | Bleu | Des devis ont été reçus, l'enchère est en cours |
| Assignée | Violet | Un worker a été sélectionné |
| En cours | Bleu | Le travail est en cours de réalisation |
| Terminée | Vert | Le travail est terminé |
| Annulée | Rouge | La demande a été annulée |
| Expirée | Gris | La durée de l'enchère est écoulée |

- Le budget estimé
- La date de création

**Appuyez sur une demande** pour voir ses détails et les devis reçus.

### 4.4 Détails d'une demande et gestion des devis

L'écran de détails affiche :
- Les informations complètes de la demande (titre, description, catégorie, urgence, budget, statut)
- La localisation sur une mini-carte
- **La liste des devis reçus** (en mode enchères)

Pour chaque devis reçu, vous voyez :
- Le nom du worker et sa note
- Le montant proposé
- Le délai estimé
- Le message du worker
- Deux boutons : **"Accepter"** (vert) et **"Rejeter"** (rouge)

**Pour accepter un devis** :
1. Consultez les devis reçus
2. Appuyez sur **"Accepter"** sur le devis choisi
3. Confirmez votre choix
4. Un **chantier** est automatiquement créé et le worker est notifié

**Pour contacter un worker** :
- Appuyez sur le bouton **"Contacter"** à côté du devis pour ouvrir une conversation

### 4.5 Chantiers (suivi des travaux)

L'onglet **"Chantiers"** affiche tous vos chantiers en cours et terminés.

**Filtres disponibles** :
- Tous
- En attente
- En cours
- Terminés

**Chaque chantier affiche** :
- Le titre du travail
- Le nom du worker assigné
- Le statut actuel
- Le montant convenu

**Écran détails du chantier** :
- Informations complètes (titre, description, montant, dates)
- **Suivi d'activité** : Historique des actions (début, progression, fin)
- **Bouton "Contacter le worker"** : Ouvrir la messagerie
- **Bouton "Évaluer"** (après complétion) : Noter le worker

### 4.6 Recherche intelligente (IA)

Depuis l'accueil, appuyez sur le bouton **"Recherche IA"** pour effectuer une recherche en langage naturel.

**Comment ça marche** :
1. Tapez votre besoin en texte libre (ex: "J'ai besoin d'un plombier pour réparer une fuite dans ma salle de bain")
2. L'intelligence artificielle analyse votre demande
3. Les résultats les plus pertinents sont affichés (workers et/ou catégories recommandées)

### 4.7 Messagerie

L'onglet **"Messages"** affiche toutes vos conversations.

**Fonctionnalités** :
- Liste des conversations avec le dernier message et la date
- **Badge rouge** sur l'icône si vous avez des messages non lus
- Appuyez sur une conversation pour l'ouvrir

**Dans une conversation** :
- Envoyez des messages texte
- Les messages affichent l'heure d'envoi
- Messages en temps réel (mise à jour instantanée)

### 4.8 Profil Client

L'onglet **"Profil"** affiche vos informations personnelles :

**Informations affichées** :
- Nom complet
- Email
- Numéro de téléphone
- Type de compte (Client)

**Actions disponibles** :
- **Modifier le profil** : Éditez votre nom, numéro de téléphone
- **Rayon de recherche** : Ajustez la distance de recherche des travailleurs (de 5 km à 100 km, par pas de 5 km). Utilisez les boutons **"-"** et **"+"** pour modifier la valeur.
- **Manuel d'utilisation** : Consultez le guide complet de l'application
- **Chatbot** : Accédez à l'assistant IA
- **Confidentialité** : Consultez la politique de confidentialité
- **Notifications** : Gérez les paramètres de notifications
- **Support** : Contactez l'équipe de support
- **Se déconnecter** : Déconnexion du compte

## 5. Guide Worker (Travailleur)

### 5.1 Accueil Worker (Carte des Jobs)

L'écran d'accueil worker affiche une **carte interactive** avec les demandes de service à proximité.

**Éléments de l'écran** :
- **En-tête** : Affiche le nombre de demandes et votre statut de disponibilité
- **Switch Disponible/Indisponible** : Activez/désactivez votre disponibilité pour recevoir des demandes
- **Filtre de catégories** : Barre horizontale avec les catégories (Toutes, Plomberie, Électricité, etc.)
- **Marqueurs sur la carte** : Chaque marqueur représente une demande de service
- **Bouton "Liste"** (bleu, en bas à droite) : Basculer vers la vue liste des demandes
- **Bouton chatbot** (orange, à droite) : Ouvrir l'assistant

**Appuyez sur un marqueur** pour voir les détails de la demande.

**Synchronisation automatique** : La carte se rafraîchit automatiquement à chaque fois que vous revenez sur cet écran.

### 5.2 Demandes disponibles

L'onglet **"Demandes"** affiche la liste de toutes les demandes disponibles correspondant à vos catégories de métiers.

**Chaque demande affiche** :
- Le titre et la description (résumée)
- La catégorie
- Le niveau d'urgence (badge coloré)
- Le budget estimé
- La distance depuis votre position
- Le mode (enchères, enchère privée, direct)
- **Badge "Devis envoyé"** (vert) si vous avez déjà soumis un devis pour cette demande

**Actions** :
- Appuyez sur une demande pour voir ses détails complets
- Si vous n'avez pas encore soumis de devis, un bouton **"Soumettre un devis"** est disponible

**Note** : Si votre profil est incomplet (pas de catégories sélectionnées), l'application vous invitera à compléter votre profil.

### 5.3 Soumettre un devis

Pour soumettre un devis sur une demande :

1. Ouvrez les détails d'une demande
2. Appuyez sur **"Soumettre un devis"** (ce bouton n'apparaît que si vous n'avez pas encore soumis de devis pour cette demande)
3. Remplissez le formulaire :
   - **Montant proposé** : Le prix que vous proposez pour réaliser le travail
   - **Délai estimé** : Le temps nécessaire pour réaliser le travail
   - **Message** : Un message pour le client (décrivez votre approche, votre expérience, etc.)
4. Appuyez sur **"Envoyer le devis"**

**Règles importantes** :
- Vous ne pouvez soumettre qu'**un seul devis par demande**
- Vous ne pouvez **pas** soumettre de devis pour une demande **expirée**
- En mode **enchère privée**, vous ne voyez que votre propre devis (pas ceux des autres workers)
- Vous pouvez **modifier** ou **supprimer** votre devis tant qu'il est au statut "En attente"

### 5.4 Mes devis

L'onglet **"Devis"** affiche tous les devis que vous avez soumis.

**Filtres disponibles** :
- Tous
- En attente
- Acceptés
- Rejetés

**Chaque devis affiche** :
- Le titre de la demande associée
- Le montant proposé
- Le statut (En attente, Accepté, Rejeté, Expiré)
- La date de soumission

**Actions sur un devis en attente** :
- **Modifier** : Changer le montant, le délai ou le message
- **Supprimer** : Retirer votre devis (action irréversible)

**Badge notification** : Un badge rouge apparaît sur l'onglet "Devis" si vous avez des devis en attente.

### 5.5 Chantiers (suivi des travaux)

L'onglet **"Chantiers"** affiche tous les chantiers qui vous ont été assignés.

**Fonctionnalités identiques au client** (voir section 4.5), avec en plus :
- **Mise à jour du statut** : Vous pouvez faire avancer le statut du chantier (démarrer, marquer comme terminé)
- **Ajout d'activités** : Enregistrez la progression des travaux

### 5.6 Messagerie

L'onglet **"Messages"** fonctionne de la même manière que pour les clients (voir section 4.7).

### 5.7 Profil Worker

L'onglet **"Profil"** affiche vos informations et donne accès à vos outils :

**Informations affichées** :
- Nom complet
- Email
- Numéro de téléphone
- Type de compte (Worker)
- Plan d'abonnement actuel (Basique ou Premium)

**Actions disponibles** :
- **Tableau de bord** : Voir vos statistiques (chantiers réalisés, note moyenne, revenus)
- **Modifier le profil** : Éditez votre profil professionnel
- **Abonnements** : Voir et gérer votre abonnement
- **Manuel d'utilisation** : Consultez le guide complet de l'application
- **Chatbot** : Accédez à l'assistant IA
- **Confidentialité** : Politique de confidentialité
- **Notifications** : Paramètres de notifications
- **Support** : Contacter l'équipe
- **Se déconnecter** : Déconnexion

### 5.8 Modifier le profil professionnel

Depuis le profil, appuyez sur **"Modifier le profil"** pour accéder à l'édition de votre profil worker :

**Champs modifiables** :
- **Catégories de métiers** : Ajoutez ou retirez des catégories (détermine les demandes visibles pour vous)
- **Description professionnelle** : Présentez votre expérience et vos compétences
- **Motivation** : Expliquez pourquoi vous êtes le bon choix
- **Tarif horaire** : Votre tarif de référence
- **Années d'expérience** : Votre niveau d'expérience
- **Rayon de service** : La distance maximale à laquelle vous acceptez de travailler (de 5 km à 100 km, par pas de 5 km). Utilisez les boutons **"-"** et **"+"** pour modifier.

Appuyez sur **"Enregistrer"** pour sauvegarder vos modifications.

### 5.9 Abonnements (Basic / Premium)

Kayniou Liggey propose deux plans d'abonnement pour les workers :

#### Plan Basique (Gratuit)
- Profil visible sur la plateforme
- 3 réponses à des demandes par mois
- Commission standard sur les chantiers
- Accès limité au chatbot (5 questions)

#### Plan Premium (10 000 FCFA / mois)
- **Visibilité prioritaire** : Votre profil apparaît en premier dans les résultats (badge TOP)
- **Réponses illimitées** : Soumettez autant de devis que vous voulez
- **Commission réduite** sur les chantiers
- **Badge Premium** visible sur votre profil
- **Chatbot illimité** : Questions sans limite

**Pour souscrire au Premium** :
1. Allez dans **Profil > Abonnements**
2. Sélectionnez le plan **Premium**
3. Confirmez votre souscription
4. Votre profil est immédiatement mis à jour avec les avantages Premium

## 6. Chatbot Assistant

Le chatbot est un assistant intelligent intégré à l'application, accessible depuis :
- Le bouton chatbot sur l'écran d'accueil (icône bulle de dialogue)
- Le menu Profil > Chatbot

### Comment l'utiliser

1. Appuyez sur le bouton chatbot
2. Tapez votre question ou votre demande dans le champ de texte
3. L'assistant vous répond avec des conseils, des informations ou de l'aide

### Exemples de questions
- "Comment créer une demande de service ?"
- "Quel est le tarif moyen pour un plombier à Dakar ?"
- "Comment devenir Premium ?"
- "J'ai un problème avec mon compte"

### Limites
- **Utilisateurs non-Premium** : 5 questions maximum. Au-delà, un message vous invite à passer au plan Premium.
- **Utilisateurs Premium** : Questions illimitées.

### Formatage des réponses
Les réponses du chatbot sont formatées avec du texte en **gras** et en *italique* pour une meilleure lisibilité.

## 7. Système de notation

Après la complétion d'un chantier, les deux parties (client et worker) peuvent s'évaluer mutuellement.

### Comment noter

1. Allez dans les détails d'un chantier **terminé**
2. Appuyez sur **"Évaluer"**
3. Remplissez l'évaluation :
   - **Note globale** : De 1 à 5 étoiles
   - **Notes détaillées** (optionnel) :
     - Qualité du travail
     - Ponctualité
     - Communication
     - Professionnalisme
   - **Commentaire** : Minimum 10 caractères, décrivez votre expérience
   - **Recommandation** : Oui/Non - Recommanderiez-vous cette personne ?
4. Appuyez sur **"Envoyer l'évaluation"**

### Visibilité des notes
- La note moyenne d'un worker est visible sur son profil
- Les évaluations aident les futurs clients à choisir le bon worker

### Gérer les notifications
1. Allez dans **Profil > Notifications**
2. Activez/désactivez les types de notifications souhaités

## 10. FAQ - Questions fréquentes

### Questions générales

**Q : L'application est-elle gratuite ?**
R : Oui, l'application est gratuite pour les clients. Les workers ont un plan Basique gratuit avec des fonctionnalités limitées, et un plan Premium à 10 000 FCFA/mois pour des fonctionnalités avancées.

**Q : Dans quels pays l'application est-elle disponible ?**
R : L'application est disponible dans 16 pays d'Afrique de l'Ouest (voir section 1).

**Q : Comment changer de pays ?**
R : Le pays est détecté automatiquement par GPS lors de l'inscription. Vous pouvez le changer manuellement en appuyant sur le sélecteur de pays (drapeau) dans le formulaire d'inscription.

### Questions Client

**Q : Comment choisir entre les modes de demande (Direct, Enchères, Enchère Privée) ?**
R :
- **Direct** : Vous connaissez déjà le worker que vous voulez. Idéal pour un travailleur recommandé.
- **Enchères Publiques** : Vous voulez comparer plusieurs offres ouvertement. Les workers voient les devis des autres.
- **Enchères Privées** : Vous voulez comparer des offres sans que les workers se voient entre eux. Plus de confidentialité.

**Q : Que se passe-t-il quand une demande expire ?**
R : Après la durée d'enchère choisie (12h à 7 jours), la demande passe au statut "Expirée". Les workers ne peuvent plus soumettre de devis. Les devis en attente sont automatiquement expirés. Vous pouvez créer une nouvelle demande.

**Q : Comment modifier mon rayon de recherche ?**
R : Allez dans **Profil**, activez le mode édition du rayon, puis utilisez les boutons **"-"** et **"+"** pour ajuster (de 5 km à 100 km).

**Q : Puis-je annuler une demande ?**
R : Oui, depuis les détails de la demande, vous pouvez l'annuler tant qu'aucun chantier n'a été démarré.

### Questions Worker

**Q : Pourquoi je ne vois pas de demandes ?**
R : Vérifiez que :
1. Votre profil est **complet** (catégories sélectionnées)
2. Votre **disponibilité** est activée (switch vert sur l'accueil)
3. Il y a des demandes dans vos **catégories** et dans votre **rayon de service**

**Q : Puis-je modifier un devis déjà soumis ?**
R : Oui, tant que le devis est au statut "En attente". Depuis l'écran "Mes devis", appuyez sur le devis puis sur "Modifier".

**Q : Comment devenir Premium ?**
R : Allez dans **Profil > Abonnements** et sélectionnez le plan Premium à 10 000 FCFA/mois.

**Q : Que signifie le badge "Devis envoyé" ?**
R : Ce badge vert apparaît sur une demande pour laquelle vous avez déjà soumis un devis. Vous ne pouvez pas soumettre un second devis pour la même demande.

**Q : Comment augmenter mon nombre de réponses en plan Basique ?**
R : Le plan Basique est limité à 3 réponses par mois. Pour des réponses illimitées, passez au plan Premium.

### Questions techniques

**Q : L'application ne se connecte pas au serveur (erreur réseau)**
R : Vérifiez votre connexion Internet (Wi-Fi ou données mobiles). Si le problème persiste, redémarrez l'application.

**Q : Le GPS ne fonctionne pas**
R : Assurez-vous que :
1. Le GPS est activé dans les paramètres de votre téléphone
2. L'application a la permission d'accéder à votre localisation
3. Vous êtes dans un endroit avec une bonne réception GPS

**Q : Je ne reçois pas le code SMS (OTP)**
R : Attendez quelques secondes. Si le code n'arrive pas après 60 secondes, appuyez sur "Renvoyer le code". En cas de problème persistant, utilisez le code de test **12345**.
